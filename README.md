# game-mods

零散游戏模组（汉化补丁、功能修复等）的发布合集。每个游戏一个文件夹，成品补丁统一挂在本仓库的 Releases。

A collection of standalone game mods (Chinese localization patches, bugfix mods, etc.) — one folder per game. Packaged builds are published under Releases.

> 补丁成品请前往 [Releases](https://github.com/fragule-hub/game-mods/releases) 页面下载。For packaged downloads, see the [Releases](https://github.com/fragule-hub/game-mods/releases) page.

## 说明 / Notes

- 各文件夹内为对应模组的工程文件（源码、数据表、文档），供审阅与二次修改；字体等大体积二进制不入库，随 Release 包分发。
- Each folder contains the mod's project files (source code, data tables, docs) for review and modification. Large binaries such as fonts are not committed and ship with the Release packages.
